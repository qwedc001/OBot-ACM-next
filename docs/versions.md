# 版本编号

版本使用 `大版本.小版本.bugfix`，可附加 `alpha`、`beta` 预发布后缀，例如 `0.6.0-alpha.1`、`0.6.0-beta.1`。

原始 OBot 功能全部迁移完成前，大版本固定为 `0`：新增功能增加第二段并将第三段归零；对当前版本修复 bug 增加第三段。例如 `0.5.1` 新增功能后为 `0.6.0`，`0.5.1` 修复 bug 后为 `0.5.2`。拆分提交本身不要求增加版本；同一发布的多个提交使用同一版本。

全部原始 OBot 功能迁移并完成验收后，才发布 `1.0.0`。后续大版本按功能与发布规划决定。

发布时同步 `pyproject.toml` 的项目版本、`framework/__init__.py` 的 `__version__` 和 `uv.lock` 中本项目的版本，并运行 `uv lock --check`。只修改本项目版本，禁止全局替换版本字符串；第三方依赖及 submodule 版本独立管理。
