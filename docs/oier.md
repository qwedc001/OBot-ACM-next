# OI 选手查询

`/oier 张三` 查询选手详情，`/oier 张三 李四 王五` 返回最多三人的简表。多词姓名使用引号，如 `/oier "First Last"`。支持原版别名 `oierdb`、`oidb`、`oi`、`oifinder`、`oifind`、`oifd`、`OI选手`、`信息学奥赛`；正式路径 `/cp.oier`。私聊直接发送，群聊需按平台要求提及机器人。

数据来自 CPCFinder 公开 OI API（`https://cpcfinder.com/api/oi/student`），不登录 OJ，不保存选手资料到本地数据库。搜索结果按姓名精确匹配（忽略大小写），多名同名者仅显示最高评分者并提示同名人数；评分相同以选手 ID 决定顺序。最多请求五页，每页 2000 条；达到上限时明确说明只在已检索候选中选取，不能保证已找到全部同名选手。空查询不会请求整个数据库。

详情包括省份、毕业届、评分、全站排名，以及按学校分组、赛事重要程度和年份排序的获奖记录；批量查询显示学校、获奖次数与 CCF 等级估算。未知学校或新赛事不会丢失。CTSC/NOIP 与部分国际奖项沿用原版归一化规则。**CCF 等级是原 OBot 规则估算，不是官方认证查询**。

每个姓名最多 80 字；超出三人时在访问网络之前拒绝。批量中的单人数据源错误不会阻止其余选手查询。长文本沿用统一分段发送，不截断记录。请求复用 HttpClient 的超时、重试、并发限制和安全错误边界；不导入原版数据库、不新增配置或迁移。

离线测试覆盖公开 API 协议夹具、分页上限、精确匹配、最高评分、同名提示、奖项归一化、估算等级、空结果和异常响应，以及真实 NoneBot/Alconna 私聊/群聊事件路由。真实 CPCFinder 服务、QQ 收图和有账号 Hydro 查询需另行验收。
